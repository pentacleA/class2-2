초등 6학년 과학 2학기 2단원 물질의 연소

서로 다른 물질을 섞으면 어떻게 될까?

삼각플라스크 속 식초에 풍선 속 가루를 쏟아보고, 물질의 성질이 변하는 예와 변하지 않는 예를 함께 살펴보자.

🎈

실험 방법

삼각플라스크에는 식초가 담겨 있고, 입구에 끼운 풍선 속에는 각각 밀가루와 탄산수소나트륨 가루가 들어있어요. 가루 쏟기 버튼을 눌러 풍선을 기울여 가루를 플라스크 안으로 넣고, 풍선이 어떻게 되는지 관찰해 보세요. 풍선이 부풀어 오른다면 기체가 생겼다는 증거예요!

🧑‍🔬 실험 1. 밀가루·탄산수소나트륨 + 식초 (풍선 실험)

두 플라스크 모두 풍선 속 가루를 쏟아 보고, 어느 쪽 풍선이 부풀어 오르는지 찾아보세요. 풍선이 부푸는 것은 기체(새로운 물질)가 생겼다는 증거예요.

물질가루를 넣었을 때 나타난 현상풍선의 변화새로운 물질이 생겼나요?변화의 종류

🃏 실험 2. 성질이 변하는 예 vs 변하지 않는 예

아래 카드 속 상황을 보고, 물질의 성질이 변하는지(화학 변화) 또는 성질이 그대로인지(물리적 변화) 골라 보세요.

성질이 변해요 (화학 변화)
성질이 그대로예요 (물리적 변화)
맞힌 개수: 0 / 12

📚 정리하기

카드 12개를 모두 골라보면 정리 내용이 열려요.

서로 다른 물질을 섞었을 때 새로운 물질이 생기면 성질이 변한 것(화학 변화)이고, 각 물질이 성질을 그대로 지닌 채 섞이거나 모양·상태만 바뀌면 성질이 변하지 않은 것(물리적 변화)이에요. 풍선이 부풀어 오르는 것은 눈에 보이지 않는 기체가 새로 생겼다는 좋은 증거가 돼요.

🔥 성질이 변하는 예 (화학 변화)

  • 탄산수소나트륨 + 식초 → 이산화탄소 발생, 풍선이 부풂
  • 종이·나무가 타서 재가 됨
  • 철이 녹슬어 성질이 달라짐
  • 우유가 상해 냄새와 맛이 변함
  • 사과 깎은 단면이 갈색으로 변함
  • 달걀을 삶으면 단단하게 굳음

💧 성질이 변하지 않는 예 (물리적 변화)

  • 밀가루 + 식초 → 반죽처럼 섞이기만 함, 풍선은 그대로
  • 얼음이 녹아 물이 됨(상태만 변화)
  • 설탕이 물에 녹아 설탕물이 됨
  • 종이를 접어 종이학을 만듦(모양 변화)
  • 유리컵이 깨짐(모양만 변화)
  • 촛농이 흘렀다가 식으면 다시 굳음

➕ 교과서보다 한 걸음 더!

실생활 속에는 성질이 변하는지 헷갈리는 경우도 많아요. 몇 가지를 더 살펴볼까요?

  • 빵 반죽이 부풀어 오를 때 — 효모가 반응해 이산화탄소를 만들기 때문에 성질이 변하는 화학 변화예요. (오늘 실험의 풍선과 원리가 비슷해요!)
  • 드라이아이스가 연기를 내며 사라질 때 — 고체 이산화탄소가 바로 기체가 되는 상태 변화로, 성질은 그대로예요(승화).
  • 폭죽이 터질 때 — 화약이 타면서 빛·열·소리를 내는 새로운 물질로 바뀌는 화학 변화예요.
  • 물을 전기 분해해 수소와 산소로 나눌 때 — 물과는 전혀 다른 성질의 두 기체가 생기는 화학 변화예요.
  • 두부를 만들 때 콩물에 간수를 넣는 것 — 단백질의 성질이 달라져 엉기므로 화학 변화예요.

💡 구별하는 방법: 색깔이나 냄새가 달라지거나, 기체·거품이 생기거나(풍선처럼!), 열과 빛을 내거나, 원래대로 되돌리기 어렵다면 성질이 변한 화학 변화일 가능성이 높아요!
